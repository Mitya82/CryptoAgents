### 🛠️ УСТАНОВЛЕННЫЕ ИНСТРУМЕНТЫ И БИБЛИОТЕКИ
**Система и IDE:**
- ОС: Windows (чистая установка на SSD)
- Python: Версия 3.14.2
- IDE: Visual Studio Code
- Доп. ПО: Obsidian (для ведения записей)

**Библиотеки Python (установлены глобально):**
- `ccxt` - единый API для 100+ криптобирж
- `pandas`, `numpy` - обработка и анализ данных
- `matplotlib` - визуализация данных и графиков
- `python-dotenv` - безопасное хранение конфигураций
- `Pillow` (PIL) - работа с изображениями

> **Примечание:** Библиотека `pandas-ta` (технические индикаторы) временно не используется из-за несовместимости с Python 3.14. Используются встроенные методы `pandas`.
